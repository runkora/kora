# Lens: Blue Ocean / ERRC grid

**What it is.** Compete by making the competition irrelevant, not by out-doing it on the same
axes. The **ERRC grid** restructures value across four moves; the **strategy canvas** plots how
players score on the factors the industry competes on, revealing where to break away.

## Procedure

1. **List the factors the category competes on.** For the agent-governance / agent-infra space:
   number of integrations, model coverage, ease of building agents, observability, policy depth,
   identity rigor, credential safety, etc. Get these from the Phase-1 dossier.
2. **Plot the strategy canvas (text form):** rate the main competitors and Orbit (high/med/low)
   on each factor. Look for where everyone clusters — clustering = red ocean.
3. **Apply the four ERRC moves:**
   - **Eliminate** — which factors the industry takes for granted should Orbit drop entirely?
     (e.g. "building agents" — Orbit is NOT a framework; eliminating it *is* the position.)
   - **Reduce** — which should be reduced well below standard? (model-routing breadth — enough to
     govern, not a router product.)
   - **Raise** — which raised well above standard? (identity rigor, pre-execution policy,
     credential isolation, traceability to a human.)
   - **Create** — which factors *no one offers* should Orbit create? (deploy-time agent identity;
     dual human+agent delegation; per-call just-in-time credential injection.)
4. The Raise + Create quadrants are your **differentiation thesis** — the spine of the pillar's
   "why us". Tie each to dual-user value.

## Orbit micro-example

Canvas shows agent-framework vendors all clustered high on "ease of building agents" and low on
"governance". Orbit's blue ocean: **Eliminate** agent-building, **Create** machine-verifiable
deploy-time identity + pre-execution policy. The pillar isn't "better agents" — it's "the only
place an agent is *governed* the way prod demands." Differentiation by non-overlap.

## Failure modes

- **Raising everything.** Blue ocean requires *eliminating/reducing* too — that's what funds the
  raises and creates focus. A grid with an empty Eliminate column is a red-ocean grid.
- **Inventing "Create" factors customers don't value.** Cross-check Create items against the JTBD
  jobs — novelty must serve a real (human or agent) job.
- **Skipping the canvas.** Without plotting the cluster you can't see where to break away.
