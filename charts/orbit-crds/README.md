# orbit-crds

![Version: 0.0.0](https://img.shields.io/badge/Version-0.0.0-informational?style=flat-square) ![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square) ![AppVersion: 0.0.0](https://img.shields.io/badge/AppVersion-0.0.0-informational?style=flat-square)

Custom resource definitions for Orbit: OrbitTenant, Connection, OAuthClient and MCPServer. Install before the orbit chart. The CRDs are templated (not a crds/ directory) so Helm and Argo CD upgrade them with the release, and each carries helm.sh/resource-policy: keep so uninstalling never deletes tenant definitions.

**Homepage:** <https://github.com/clear-route/orbit>
