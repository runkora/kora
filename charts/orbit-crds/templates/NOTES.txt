kora CRDs installed: orbittenants, connections, oauthclients, mcpservers, skillmarketplacesources, inferenceproviders, sandboximages (orbit.io).

Install the orbit chart next, into the namespace kora will run in:

  helm upgrade --install orbit oci://ghcr.io/clear-route/charts/orbit \
    --version {{ .Chart.Version }} --namespace {{ .Release.Namespace }}

The CRDs carry helm.sh/resource-policy: keep. Uninstalling this release leaves
them, and every OrbitTenant, Connection, OAuthClient, MCPServer,
SkillMarketplaceSource, InferenceProvider and SandboxImage, in place.
